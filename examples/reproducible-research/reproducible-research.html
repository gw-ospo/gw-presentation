Part two

From believable to rebuildable

Three habits make a result rebuildable

Version everything

Code, inputs, and figure scripts live in version control from day one.

Share code and data

Open licenses and archived releases with a DOI let others start where you stopped.

Automate the pipeline

One command regenerates every figure, so nothing depends on memory.

Your most important collaborator is you, six months from now.

If it can’t be rebuilt, it isn’t finished.

Pick one project this semester: version it, share it, automate it.
