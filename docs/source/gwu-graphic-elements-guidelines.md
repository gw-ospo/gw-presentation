# GWU Graphic Elements — Presentation Usage Guidelines

> Based on: [GWU Brand Guidelines — Graphic Elements](https://communications.gwu.edu/brand-guidelines/graphic-elements)  
> Applies to: Slide presentations and documents using the downloaded **Chevron** and **Additional Elements** asset packs.

---

## Guiding Principles

GWU's graphic elements are designed to support — not dominate — a composition. Their use in presentations should reflect these core intentions:

- **Making Connections:** Use graphic elements to create visual links between content blocks and guide the viewer's eye.
- **Elevating Momentum:** Elements like chevrons and step accents imply forward and upward motion; orient them accordingly.
- **Restraint and Detail:** Elements draw from GWU's architecture, campus, and city. Use them as considered accents, not decorative filler.
- **Collective Impact:** These elements gain strength through consistent, disciplined use — not overuse.

---

## Chevrons

Chevrons signal forward motion and progress. In a slide context, they can direct attention toward key information, headlines, or calls to action.

### Formats Available

- **Chevron Ribbons:** Thin rectangular strips containing the chevron pattern. Use as horizontal accents — e.g., beneath a slide title or above a footer area — to draw the eye across the layout.
- **Chevron Chips:** Square-format chevron elements. Use to anchor a content block or section, such as alongside a pull quote or data point.
- **Chevron Background:** The pattern at full bleed, with content placed over it. Suitable for section-divider slides or title slides.

### Usage Rules for Presentations

- Chevrons must **always point to the right**, reinforcing the idea of forward motion.
- Use **no more than three colors** within a single slide layout to avoid visual overload.
- The pattern may appear with a **one-color fill, two colors, tone-on-tone fills, or a fading gradient**. Tone-on-tone works well as a text background.
- **Do not combine** a chevron background with chevron chips on the same slide.
- Use chevrons **sparingly** — not on every slide. Reserve them for title slides, section breaks, or key moments.
- Use only **approved color combinations** from the GWU core color palette.

## Additional Elements

The Additional Elements pack includes three distinct elements: the **Gate Crossbar**, the **Six-Pointed Star**, and the **Five-Pointed Star**. Each has specific rules for use.

### Gate Crossbar

Modeled after the interlocking motif at the top of the Professor's Gate on the Foggy Bottom campus.

- Use as a **single-line divider** between sections of text or content — not tiled into a repeating pattern.
- Best placed near text to anchor its use contextually.
- Set in a **single color only**.
- Do not use more than **one pattern element per slide**.

### Six-Pointed Star

Recalls the design of George Washington's battle flag.

- Works best as a **background texture** that bleeds off the slide edge — suitable for section-divider slides.
- Set in a **single color only**.
- Do not use as an isolated badge or icon.
- Do not use more than **one pattern element per slide**.
- Avoid using on **content-heavy slides**; patterns should never dominate the layout.

### Five-Pointed Star

Reflects the stars on the D.C. flag; adds a local civic dimension to compositions.

- Can be used individually in layouts as a supporting accent.
- Must always sit **vertically, with one tip pointing directly upward**.
- **Do not use five-pointed stars to create a repeating pattern.**
- Set in a **single color only**.
- Do not combine with the six-pointed star pattern on the same slide.

---

## General Rules Across All Elements

| Rule | Detail |
|---|---|
| One pattern per slide | Never combine Gate Crossbar, Six-Pointed Star, or Five-Pointed Star patterns on the same slide |
| Single-color patterns | All Additional Elements must be set in a single color |
| No dominance | Graphic elements must support the composition — never become the primary visual |
| Brand colors only | Use elements in GWU core colors (GW Blue, GW Buff, and approved accents) |
| Consistency | Choose one graphic element style and use it consistently throughout the deck |

---

## Recommended Slide Applications

| Slide Type | Suggested Element |
|---|---|
| Title / Cover slide | Chevron background (tone-on-tone) or Six-Pointed Star background |
| Section divider | Chevron ribbon or Gate Crossbar as divider line |
| Content slide (data, text) | Chevron chip to anchor a key stat or pull quote |
| Closing / thank-you slide | Chevron background or Five-Pointed Star accent |
| Text-heavy slide | Gate Crossbar as a subtle section divider; avoid pattern backgrounds |
