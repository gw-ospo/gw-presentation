## Typography

GWU's brand uses three typefaces, each with a defined role. Pairing two typefaces tends to work best; using all three simultaneously is permissible but should be intentional. Mix and match weights for visual interest.

### 1. Gazzetta *(Primary — Headlines)*

- **Style:** Serif; inspired by classic newspaper typography, refined for modern use
- **Uses:** Headlines, subheads, key marketing moments
- **Notes:** Best for short headlines or phrases; signals credibility and academic rigor
- **Variants:** Regular, Italic

### 2. Avenir Next *(Primary — Body)*

- **Style:** Clean, sans-serif
- **Uses:** Body copy, subheads, captions, call-outs
- **Notes:** Works well across digital and print; ensures consistency with GWU signage and stationery
- **Variants:** Regular, Italic

### 3. Source Serif *(Accent — Use Sparingly)*

- **Style:** Serif; more scholarly appearance
- **Uses:** Headline emphasis, short callouts
- **Notes:** Provides contrast against the two sans-serif typefaces
- **Variants:** Regular, Italic

### Color Usage Guidance

- **Core colors** (GW Blue, GW Buff, Potomac, Navy Yard, and White) should dominate and establish brand presence.
- **Secondary accents** (Row House, Blossom, Parchment, Blue Fog, Patina) should be used sparingly — never dominating the layout.
- Use a **higher ratio of white** in more formal presentations for a clean, elevated look.
- Most projects should lean on the **controlled spectrum** (core colors); shift to the expressive spectrum only if the project calls for it.
